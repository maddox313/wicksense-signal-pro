# WickSense Signal Pro

Ultimate stock trade detection SaaS — buy/sell signals, auto trading, risk management, and broker integration.

## Quick Start

```bash
cd C:\Users\clggl\Projects\wicksense-signal-pro
npm install
npm run dev
```

Open http://localhost:3000

## Alpaca Setup

Add to apps/web/.env:
ALPACA_API_KEY=your_key
ALPACA_SECRET_KEY=your_secret
ALPACA_PAPER=true

Without keys, simulated market data is used.
